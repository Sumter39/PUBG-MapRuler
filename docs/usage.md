# 使用说明

## 前置条件

- Windows 10 / 11
- 游戏设为**无边框窗口 / 窗口化**（独占全屏下任何 overlay 都无法绘制）
- 构建才需要 Python 3.8+ 与 `pip install pyinstaller pywin32`；直接用 EXE 不需要

## 构建与运行

```bash
python build.py      # 产出 dist/PUBG-MapRuler.exe
```

数据目录为便携模式，跟 EXE 走，不写注册表、不落 `%LOCALAPPDATA%`：

```
<EXE 所在目录>\PUBG-MapRuler-Data\
  settings.ini     配置（热键、面板位置、透明度等）
  place.log        启动时的显示器枚举与面板定位记录
  dxgi.log         抓屏通道与格式记录
  last_scan.png    最近一次识别留帧
  frames/          最近 20 张识别留帧归档
  scan.log         每次扫描一行 JSON 的全量日志
```

## 操作

| 操作 | 方式 |
| --- | --- |
| 显示 / 隐藏面板 | 全局热键（默认 `右Alt + ,`）；托盘左键或菜单 |
| 自定义热键 | 面板右下「?」→ 点热键框 → 按新组合键（修饰键限定左/右 Alt、左/右 Ctrl，主键任意字母/数字/F1~F24/常用符号/Space/Enter/Tab） |
| 画轨迹 | 按 M 开地图 → `Alt + 右键` 标点连线（游戏原生交互，允许弯折） |
| 测距 | 点面板「测量」按钮，量出折线起点到终点的直线距离；点击某一行结果 = 清掉该行 |
| 设置 | 托盘右键 → 设置（透明度 / 置顶 / 网格辅助线 / 对齐补偿） |

## 行为约定

- 点位投影层永远 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，不拦截任何鼠标，游戏内点地图、标点、拖拽照常；只有控制面板可交互。
- 多显示器下面板默认放**副屏**（主屏留给投影）；手动拖动后的位置会被记住。
- 抓帧前程序会把自己的图层临时透明，识别帧里只有游戏画面。
- 测距只认**有连线**的标记（孤立标记不记点）；只有直线量距离，折线认出但距离留空。
- 面板右下「?」从主面板右侧滑出，不弹独立窗口。

## 已知限制

- 点位投影只支持完整地图视图（按 M 打开），不支持右上角小地图。
- 队伍标记颜色以游戏 **Normal 色盲模式**的屏幕实色为准：1 黄 / 2 橙 / 3 青 / 4 绿；其他色盲模式退回黄色通认。旧配置里的 2 红 / 3 深蓝会在启动时自动刷新。
- 同一条轨迹在不同缩放档位下测距值应一致（比例尺按当帧网格重测）；若差异明显，多为画面里还有别的同色标记被误串，请清掉多余标记再测。
- 深度放大时 100 m 白细格被地形淹没，比例尺靠 1 km 大格判定。
- HDR 屏优先 DXGI 桌面复制，失败自动回退 GDI 并做色调补偿。
